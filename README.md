# Tai chi


https://sibtomcat.itch.io/tai-chi-demo-scene


This is something between a demo scene and a study project. Trying to get a handle on Godot and the use of assets.

Created in cooperation with *xolatgames*.

**Camera movement:** press LMB and move, mouse wheel, QWEASD.

**Camera rotation:** ZXC.

**Exit:** ESC.

**Camera acceleration:** Shift

**Full screen on/off:** F11


What's currently available:

* Courtyard (pool) — “SwimmingPool” (Sweet Home 3D\Blog).
* Character and animation — Tomcat's Godot tutorial.
* Camera movement code — Godot 4 Debug Camera.
* Camera movement restriction.
* Trees with wind effect — Create trees with wind effect.
* Water shader.
* Skin shader (based on gd-character-creation, reworked).
* Wind effect flowers.

**Assets by MH Team:** *punkduck*.

Godot 4.4.1
